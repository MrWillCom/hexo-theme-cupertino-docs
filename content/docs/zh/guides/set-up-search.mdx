Cupertino 主题使用 [Pagefind](https://pagefind.app/) 进行搜索。搜索功能默认是关闭的，因为它需要额外配置。

<Steps>
<Step>

## 在配置中启用

```yml title="_config.cupertino.yml"
search: true
```

</Step>

<Step>

## 安装 Pagefind

```npm
npm install pagefind
```

</Step>

<Step>

## 添加脚本

```json title="package.json"
{
  "scripts": {
    "index": "pagefind --site public"
  }
}
```

</Step>

<Step>

## 构建索引

```npm
npm run build
npm run index
```

<Callout type="info">
  必须先构建再索引，否则没有内容可供索引。你也需要同步调整部署命令或 CI/CD。
</Callout>

</Step>

<Step>

## 创建搜索页面

```npm
npm exec hexo new page 'search'
```

```md title="source/search/index.md"
---
type: search
---
```

完成！现在你的搜索页面就绪，访问地址为 `/search`。

</Step>
</Steps>
