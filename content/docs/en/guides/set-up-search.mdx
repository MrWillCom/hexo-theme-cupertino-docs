title: 'Set Up Search'
---

import { Step, Steps } from 'fumadocs-ui/components/steps'

Theme Cupertino uses [Pagefind](https://pagefind.app/) for searching. Search features are disabled initially because it requires to be set up.

<Steps>
<Step>

## Enable in configuration

```yml title="_config.cupertino.yml"
search: true
```

</Step>

<Step>

## Install Pagefind

```npm
npm install pagefind
```

</Step>

<Step>

## Add script

```json title="package.json"
{
  "scripts": {
    "index": "pagefind --site public"
  }
}
```

</Step>

<Step>

## Build index

```npm
npm run build
npm run index
```

<Callout type="info">
  You have to build before indexing, or there will be nothing to index. You should also adjust your
  deployment commands or CI/CD.
</Callout>

</Step>

<Step>

## Create search page

```npm
npm exec hexo new page 'search'
```

```md title="source/search/index.md"
---
type: search
---
```

Done! Now your search page is ready at `/search`.

</Step>
</Steps>
