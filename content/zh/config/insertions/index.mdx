# 注入

注入是将其他内容集成到博客中的最佳方式。如果你想添加即时聊天、自定义 CSS 等，可以使用注入。目前，Cupertino 主题支持以下注入位置：

```yml filename="_config.cupertino.yml"
insertions:
  head:
    ending: ''
  body:
    ending: ''
  comments_section: ''
```

`comments_section` 是评论区的特殊位置。它遵循文章 front-matter 中的 `no_comments` 选项。如果 `no_comments` 设置为 true，`comments_section` 中的注入将不会渲染。
