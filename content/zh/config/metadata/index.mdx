# 元数据

## Favicon

Favicon 是你博客的图标，即浏览器标签页上显示的图标。

![浏览器标签页上显示的 Favicon](./img/favicon.jpg)

```yml filename="_config.cupertino.yml"
favicon: <favicon-路径>
```

该值会直接传给 [`favicon_tag`](https://hexo.io/docs/helpers#favicon-tag)。

## Manifest

[`manifest.json`](https://developer.mozilla.org/docs/Web/Manifest) 的路径，主要用于 PWA。

```yml filename="_config.cupertino.yml"
manifest: <manifest-路径>
```
