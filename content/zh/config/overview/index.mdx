# 总览

你的博客项目中有两个配置文件。博客根目录下的 `_config.yml` 是博客配置。Cupertino 主题在其目录中保留默认配置。要覆盖默认值，你需要在根目录创建 `_config.cupertino.yml`。创建此配置文件后，项目结构应如下所示：

import { FileTree } from 'nextra/components'

<FileTree>
  <FileTree.Folder name="your-blog" defaultOpen>
    <FileTree.File name="_config.yml" />
    <FileTree.File name="_config.cupertino.yml" />
    <FileTree.File name="..." />
    <FileTree.Folder name="source">
      <FileTree.File name="..." />
    </FileTree.Folder>
    <FileTree.Folder name="..." />
  </FileTree.Folder>
</FileTree>
