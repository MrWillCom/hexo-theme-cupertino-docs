彩虹横幅默认禁用。启用后它会在每年六月出现：

```yml filename="_config.cupertino.yml"
rainbow_banner: true
rainbow_banner_colors:
  - '#e50000'
  - '#ff8d00'
  - '#ffee00'
  - '#008121'
  - '#004cff'
  - '#760188'
rainbow_banner_shown: auto
rainbow_banner_month: 6
```

`rainbow_banner_colors` 接受一个 CSS 颜色数组。`rainbow_banner_shown` 接受 `auto` 或 `always`。

要让彩虹横幅全年显示，请将 `rainbow_banner_shown` 改为 `always`。
